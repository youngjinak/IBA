# 최종버전 — 신용위험 분류 모델

이 폴더는 1조 발표에 사용한 **RBF 커널 SVC 단일 모델**의 자료를 모은 곳이다. `Risk`가 알려진 800명의 학습 데이터로 모델을 검증·학습하고, 정답이 비어 있는 200명의 `Risk`를 `good` 또는 `bad`로 예측한다. 아래 수치는 `1조_분류_코드_최종.ipynb`에 저장된 실행 결과이며, 별도의 새 평가를 수행한 값은 아니다.

| 파일 | 내용 |
|---|---|
| `1조_분류_코드_최종.ipynb` | 전처리, 모델 설정·비교, 교차검증, 최종 학습·예측 및 시각화 코드 |
| `IBA_분류_1조.pdf` | 최종 발표 자료 |
| `이영진_분류_7차.csv`, `이영진_분류_8차.csv` | 폴더에 남아 있는 예측 CSV. 이번 정리에서는 내용과 생성 조건을 확인하지 못했으므로 아래 검증 점수의 근거로 사용하지 않음 |

## 모델과 전처리

- 원본 변수 9개를 사용한다. `Job`은 숫자로 저장되어 있지만 직업 범주로 취급해 문자열로 바꾼 뒤 원핫 인코딩한다. `Sex`, `Housing`, `Purpose`도 원핫 인코딩한다.
- `Checking account`와 `Saving accounts`는 알려진 수준을 순서값으로 바꾸고, 빈값 여부를 별도 플래그로 보존한다. 순서값의 빈자리는 각각 2.0, 2.5로 채우지만 플래그로 원래 빈값임을 구분한다. `Age`, `Credit amount`, `Duration` 및 계좌 파생변수에는 `StandardScaler`를 적용한다.
- 최종 분류기는 `SVC(kernel='rbf', C=0.5, gamma=0.1, class_weight=None)`이다. SVC의 결정점수를 예측 대상 집단 안에서 순위로 바꾸고, 그 순위에 임계값을 적용한다. 별도의 모델을 결합한 앙상블은 아니다.

## 검증 결과

| 지표 | Good | Bad |
|---|---:|---:|
| 정밀도 | 0.8472 | 0.4977 |
| 재현율 | 0.6932 | 0.7073 |
| F1 Score | 0.7621 | **0.5836** |

보고 기준은 **Bad F1**이다. 위 결과는 20개 분할 시드 × 5-fold의 held-out 예측에서 계산했다. 각 fold의 학습 부분에서 모델·전처리를 적합하고 판정 임계값을 선택한 뒤, 제외된 fold에서 평가했다. Bad F1 0.5836은 fold별 F1의 평균이다. 노트북에는 시드별 평균에서 계산한 95% 구간 **0.5797~0.5876**도 기록되어 있다. 전체 학습 800명에서 다시 계산한 훈련 F1 0.7019는 일반화 성능을 나타내지 않아 보고 점수로 사용하지 않는다.

실제 예측에 사용할 순위 임계값은 학습 데이터의 **30개 시드 OOF 최적 임계값 평균 0.5921**로 정했다. 따라서 검증 F1 0.5836은 fold별로 학습 부분에서 임계값을 고른 절차의 성능이며, 최종 고정 임계값 0.5921을 독립 시험 데이터에서 평가한 점수라고 해석하면 안 된다. 정답 입력 200명의 실제 `Risk`가 없으므로 이 대상에 대한 F1은 여기서 계산할 수 없다.

## 다시 실행할 때

프로젝트 루트의 `분류_학습_데이터셋.csv`와 `정답 입력 데이터.csv`를 그대로 두고 노트북 셀을 순서대로 실행한다. 프로젝트 루트 또는 이 폴더를 작업 디렉터리로 사용하면 노트북의 파일 탐색 코드가 상위 폴더까지 확인한다. 마지막 셀은 입력 데이터의 행·칼럼을 유지하고 `Risk`만 채워 작업 디렉터리에 `SVC_예측_제출.csv`를 저장한다. 수치와 그림을 재현하려면 노트북 전체 실행이 필요하다.
