# 신용위험 분류 프로젝트

이 폴더에는 발표에 사용한 최종 자료, 이전 모델 버전, 예측 재생성에 필요한 원본 데이터가 있습니다.

| 파일 | 용도 |
|---|---|
| `분류_학습_데이터셋.csv` | Risk 정답이 있는 학습 데이터 800행 |
| `정답 입력 데이터.csv` | Risk를 예측해 채울 대상 데이터 200행 |
| `최종버전/IBA_분류_1조.pdf` | 최종 발표 자료 |
| `최종버전/1조_분류_코드_최종.ipynb` | 전처리, 검증, 최종 SVC 학습 및 예측 코드 |
| `최종버전/결과보고서.md` | 최종 모델의 구성과 검증 결과 요약 |
| `단일모델버전/` | 1·2·4차 개별 모델 실험 코드와 결과보고서 |
| `앙상블버전/` | 3·5차 앙상블 코드와 결과보고서 |

이전 버전의 예측 CSV는 정리하면서 삭제했습니다. `최종버전`에 남아 있는 7·8차 CSV의 생성 조건은 확인하지 못했습니다. 새 예측 파일이 필요하면 프로젝트 폴더 또는 `최종버전` 폴더를 작업 디렉터리로 두고 최종 노트북을 실행하세요. 노트북의 마지막 예측 셀이 `SVC_예측_제출.csv`를 생성하며, 기존 데이터의 행과 칼럼을 유지하고 `Risk`만 채웁니다.

발표 자료의 Bad F1 **0.5836**은 학습 데이터 내부의 20시드 × 5-fold 교차검증 결과입니다. 정답 입력 데이터 200행의 실제 Risk 정답은 이 폴더에 없으므로, 해당 파일의 F1을 여기서 계산할 수는 없습니다.

이전 1~5차 버전은 이 폴더의 `단일모델버전/`(1·2·4차)과 `앙상블버전/`(3·5차)으로 분류했습니다. 각 버전은 대표 실행 파일 `모델코드.py`와 `결과보고서.md`를 공통 이름으로 사용하며, 필요한 모델별 구현 파일도 함께 있습니다. 이전 자료 보관 폴더의 나머지 탐색·제작 자료와 중복 원본 데이터 사본은 정리했습니다.
