# 3차 최종 모델 설명

## 목적

학습 데이터 800명으로 신용위험을 학습하고, 정답 입력 데이터 200명의 `Risk`를 `good` 또는 `bad`로 예측한다. 평가 기준은 `bad` 클래스를 양성으로 계산한 F1 score다.

## 최종 구조

3차 최종 모델은 **Random Forest와 CatBoost의 예측 확률을 균형 로지스틱 회귀로 결합한 스태킹 앙상블**이다.

```text
입력 변수 10개
   ├─ Random Forest ─┐
   │                 ├─ 두 모델의 Bad 확률 ─ 균형 로지스틱 회귀 ─ 임계값 0.50 ─ Risk
   └─ CatBoost ──────┘
```

Random Forest와 CatBoost가 각 사람의 `bad` 확률을 계산한다. 두 확률을 새로운 입력값으로 사용해 균형 로지스틱 회귀가 최종 Bad 점수를 만든다. 최종 점수가 0.50 이상이면 `bad`, 미만이면 `good`으로 분류한다.

## 입력 변수와 결측치

모델은 다음 원본 변수 9개와 계좌 결측 상태에서 만든 파생변수 1개를 사용한다.

| 구분 | 변수 |
|---|---|
| 수치형 | Age, Credit amount, Duration |
| 범주형 | Sex, Job, Housing, Saving accounts, Checking account, Purpose |
| 파생 범주형 | Account information |

`Saving accounts`와 `Checking account`의 빈칸은 임의의 계좌 수준으로 복원하지 않고 `Unknown`이라는 범주로 유지한다. `Account information`은 두 계좌가 모두 관측됐는지, 한쪽만 관측됐는지, 모두 관측되지 않았는지를 표현한다.

## 기본 모델 설정

### Random Forest

- 트리 수: 400
- 최소 잎 표본 수: 2
- 후보 변수 선택: `sqrt`
- 클래스 가중치: `balanced_subsample`
- 범주형 변수: 원-핫 인코딩

### CatBoost

- `iterations=500`
- `depth=5`
- `learning_rate=0.05`
- `l2_leaf_reg=13`
- `random_strength=1`
- `auto_class_weights="Balanced"`
- 범주형 변수를 CatBoost에 직접 전달

초기 CatBoost의 `l2_leaf_reg=5`에서 7·10·13·16을 비교한 결과, seed 42의 동일한 5×3 중첩 교차검증에서 L2=13의 Bad F1이 0.5874로 가장 높았다.

## 스태킹 학습 방법

메타 모델이 기본 모델의 학습 데이터 내부 예측을 그대로 사용하면 과적합될 수 있다. 이를 줄이기 위해 학습 데이터 800명을 5분할하고, 각 사람은 자신을 학습에서 제외한 Random Forest와 CatBoost에서 OOF(Out-of-Fold) Bad 확률을 받는다.

이렇게 얻은 800개의 Random Forest 확률과 CatBoost 확률로 균형 로지스틱 회귀 메타 모델을 학습한다. 제출 데이터를 예측할 때는 Random Forest와 CatBoost를 800명 전체로 다시 학습하고, 두 확률을 학습된 메타 모델에 전달한다.

## Good 우선 규칙

기존 1·2·3차에서 사용한 규칙을 유지했다. 각 학습 부분에서 실제 `bad` 사례의 최소 대출기간과 최소 대출금액을 계산하고, 다음 중 하나를 만족하면 최종 예측을 `good`으로 변경한다.

- `Duration`이 학습 부분의 Bad 최소 기간보다 짧음
- `Credit amount`가 학습 부분의 Bad 최소 금액보다 작음

검증할 때는 검증 정답을 사용하지 않고 해당 학습 부분에서만 기준을 계산했다. 최종 제출 예측에서는 800명 전체 학습 데이터에서 기준을 계산한다.

## 검증 결과

### 세부 설정 및 임계값 탐색

| 설정 | Bad F1 |
|---|---:|
| 기존 L2=5, 임계값 0.50 | 0.5835 |
| L2=10, 임계값 0.50 | 0.5870 |
| **L2=13, 임계값 0.50** | **0.5874** |
| L2=16, 임계값 0.50 | 0.5833 |

L2=13에서 임계값 0.45~0.55를 0.01 단위로 비교한 결과 0.50이 가장 높았다.

### 반복 5분할 교차검증

탐색에 사용하지 않은 seed 101·202·303으로 L2=10과 L2=13을 비교했다.

| 설정 | 평균 Bad 정밀도 | 평균 Bad 재현율 | 평균 Bad F1 | F1 표준편차 |
|---|---:|---:|---:|---:|
| L2=10 | 0.4990 | 0.6944 | 0.5807 | 0.0136 |
| **L2=13** | **0.4995** | **0.7056** | **0.5849** | **0.0075** |

L2=13은 L2=10보다 반복 평균 Bad F1이 0.0043 높고 변동성이 작았다. 다만 표본이 800명이고 차이가 작으므로 큰 성능 향상으로 단정하기보다는 현재 후보 중 조금 더 안정적인 설정으로 해석한다.
