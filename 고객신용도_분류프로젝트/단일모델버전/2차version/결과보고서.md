# 2차version · 로지스틱 회귀와 CatBoost

대표 실행 파일은 `모델코드.py`다. `python 모델코드.py`로 네 단일 모델을 모두 실행하거나, `python 모델코드.py --model catboost`처럼 하나만 선택할 수 있다. 실제 모델 정의와 공통 전처리는 같은 폴더의 개별 Python 파일에 있다.

## 평가 방법

- 원본 학습 800명(good 560명, bad 240명)을 사용했다. 저축계좌 복원본과 정답 입력 200명은 평가에 사용하지 않았다.
- 두 모델과 비교용 1차 랜덤포레스트에 **동일한 계층 5분할 교차검증**을 적용했다. shuffle=True, seed=42. 매번 640명으로 학습하고 나머지 160명을 예측했다.
- 각 사람을 자신이 학습에 포함되지 않은 모델로 한 번씩 예측한 800개 결과(OOF)를 합쳐 F1을 계산했다. 주 지표는 **Macro F1**, bad를 양성으로 한 F1·정밀도·재현율도 함께 확인했다.
- 모델의 bad 점수가 **0.5 이상이면 bad**다. good과 bad의 예측 점수 합은 1이다.
- 기존 good 우선 규칙을 유지했다. 기간 또는 금액이 해당 학습 부분의 bad 최솟값보다 작으면 good이다. 각 분할에서 학습 부분만으로 기준을 계산했고 이번에는 모두 6개월·433 DM이었다.
- 입력은 원본 9개 특성과 계좌 정보 상태다. Risk는 입력에 넣지 않고 정답으로만 사용했다. 원본 ID는 제외했다. 계좌 결측은 Unknown으로 유지했다.
- 하이퍼파라미터나 판정 기준을 점수에 맞춰 탐색하지 않은 기본 비교다. 모델 결합은 하지 않았다.

## 모델 구성

| 모델 | 설정 |
|---|---|
| 로지스틱 회귀 | 수치 표준화, 범주 원핫 인코딩, C=1, class_weight=balanced, max_iter=3000 |
| CatBoost | 범주형 직접 처리, 나무 500개, depth=5, learning_rate=0.05, l2_leaf_reg=5, auto_class_weights=Balanced |
| 랜덤포레스트 비교 기준 | 1차와 동일: 나무 400개, 말단 최소 2명, class_weight=balanced_subsample, max_features=sqrt |

스케일러·인코더는 각 학습 부분에서만 학습했다. CatBoost도 검증 정답을 학습이나 조기 종료에 사용하지 않았다. 두 새 모델 모두 교차검증 후 전체 800명으로 최종 학습까지 실행해 정상 동작을 확인했다.

## 결과

아래는 각 행이 검증 대상일 때의 예측 800개를 합친 결과다. 모든 모델에 good 우선 규칙을 적용했다.

| 모델 | Macro F1 | good F1 | bad F1 | bad 정밀도 | bad 재현율 | 정확도 |
|---|---:|---:|---:|---:|---:|---:|
| 로지스틱 회귀 | **0.6535** | 0.7423 | 0.5647 | 0.4732 | **0.7000** | 0.6763 |
| CatBoost | **0.6709** | 0.7931 | 0.5487 | 0.5247 | 0.5750 | 0.7163 |
| 1차 랜덤포레스트 설정 | **0.6672** | 0.8028 | 0.5316 | 0.5385 | 0.5250 | 0.7225 |

**이번 비교에서는 CatBoost의 Macro F1이 가장 높지만, 랜덤포레스트와의 차이는 0.0036으로 작다.** CatBoost가 확실히 우수하다고 단정하기에는 부족하다. 로지스틱 회귀는 bad를 더 많이 찾아 재현율이 높지만, 실제 good도 bad로 잘못 분류하는 경우가 많았다. 목표를 bad F1로 바꾸면 이번 표의 순위도 달라진다.

| 분할별 Macro F1 | 로지스틱 회귀 | CatBoost | 랜덤포레스트 |
|---|---:|---:|---:|
| 1 | 0.7046 | 0.7352 | 0.6819 |
| 2 | 0.6558 | 0.6755 | 0.6834 |
| 3 | 0.6207 | 0.6546 | 0.5975 |
| 4 | 0.6368 | 0.6473 | 0.7034 |
| 5 | 0.6457 | 0.6391 | 0.6606 |
| 분할 점수 평균 ± 표준편차 | 0.6527 ± 0.0318 | 0.6704 ± 0.0387 | 0.6654 ± 0.0409 |

분할별 F1의 평균과 800개 예측을 합친 F1은 계산 순서가 달라 조금 다르다.

| 오류와 정답 개수 | 로지스틱 회귀 | CatBoost | 랜덤포레스트 |
|---|---:|---:|---:|
| 실제 good → good | 373 | 435 | 452 |
| 실제 good → bad | 187 | 125 | 108 |
| 실제 bad → good | 72 | 102 | 114 |
| 실제 bad → bad | 168 | 138 | 126 |

good 우선 규칙은 전체 OOF 14명에게 적용됐고, 그중 실제 bad는 없었다. 모델 단독 예측에서 로지스틱은 3명, 랜덤포레스트는 1명이 good으로 바뀌었으며 CatBoost는 바뀐 사람이 없었다. 규칙 미적용 Macro F1은 각각 로지스틱 0.6502, 랜덤포레스트 0.6662, CatBoost 0.6709였다.

## 해석 시 구분할 점

1차에서 제시한 Macro F1 **0.6837**은 한 번의 640/160 분할에서 나온 값이다. 이번에는 5분할 OOF 결과이므로 그 수치와 직접 비교하면 안 된다. 위 랜덤포레스트 비교 기준은 두 새 모델과 같은 5분할에서 다시 평가한 값이다.

분할별 표준편차는 성능의 흔들림을 보여 주는 값이며 신뢰구간이 아니다. 한 번의 5분할 비교이고 이미 전체 데이터로 여러 탐색을 한 이력이 있으므로 외부 독립 검증 결과나 확정적인 모델 우열로 해석하지 않는다. 이후 최적화한다면 기준 선택과 성능 확인을 구분해야 한다.

## 파일 및 실행

- `logistic_regression.py`: 로지스틱 회귀, 공통 전처리·교차검증, 선택적 랜덤포레스트 비교 코드.
- `catboost_model.py`: CatBoost 코드. 같은 폴더의 로지스틱 파일에서 공통 전처리·평가 함수를 가져온다. 두 모델의 예측을 섞는 것은 아니다.
- `결과보고서.md`: 본 보고서.

필요 패키지: numpy, pandas, scikit-learn, catboost. 이번 실행은 Python 3.13.15, numpy 2.5.3, pandas 3.0.5, scikit-learn 1.9.1, CatBoost 1.2.10의 임시 가상환경을 사용했다.

```powershell
python -B logistic_regression.py
python -B catboost_model.py
# 동일 분할의 랜덤포레스트 비교까지 재현하려면:
python -B logistic_regression.py --with-rf
```

해당 패키지가 기본 Python에 없다면 이번에 사용한 실행 파일은 `$env:TEMP\iba-savings-analysis-env\Scripts\python.exe`이다.

실행 결과는 콘솔에 출력되며 모델 객체는 `run()`의 두 번째 반환값으로 얻을 수 있다. 요청대로 CSV·이미지·실행요약·모델 가중치 파일은 저장하지 않는다. 기존 1차 모델과 예측 CSV도 변경하지 않았다.
